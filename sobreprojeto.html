Sobre o Projeto

Tecnologia e sentimento, unidos em um único projeto.

Este projeto nasceu de uma das formas mais sinceras que encontrei de expressar o que sinto: transformando meus sentimentos em algo que pudesse criar com minhas próprias mãos.

Desenvolvido como parte dos meus estudos em desenvolvimento web, este site foi dedicado inteiramente à Maria, uma pessoa que se tornou extremamente importante na minha vida. Mais do que uma simples página na internet, quis criar um espaço para registrar nossa história, relembrar momentos especiais e demonstrar um pouco do amor que sinto por ela.

Durante o desenvolvimento, utilizei HTML e CSS para construir as páginas, organizar os conteúdos, trabalhar com imagens, criar layouts responsivos e explorar diferentes possibilidades de estilização. Também experimentei recursos como GIFs, fontes personalizadas e reprodução de música, buscando proporcionar uma experiência que combinasse com a proposta do projeto.

Por ser um projeto de estudos, cada página também representa uma oportunidade de aprendizado. Através dele, posso colocar em prática os conhecimentos que venho acquiring, experimentar novas ideias, identificar erros e aprimorar minhas habilidades no desenvolvimento web.

Escolhi unir duas coisas que têm um significado especial para mim: a programação, área na qual estou construindo meu futuro profissional, e a Maria, que faz parte dos momentos mais felizes da minha vida.

No fim, este projeto representa mais do que meu aprendizado em tecnologia. É a prova de que até mesmo algo criado durante o processo de aprendizagem pode carregar um significado enorme. Cada detalhe foi pensado com carinho, e cada linha de código contribuiu para transformar uma ideia em uma pequena homenagem à pessoa que amo.
